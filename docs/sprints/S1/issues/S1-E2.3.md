# [S1-E2.3] POST /api/auth/refresh (회전) + POST /api/auth/logout

**Plan**: S1 / Must / FEAT / 1.0 MD / W2
**BlockedBy**: S1-E2.2 · **FE 차단**: web S1-WF3.2 (로그아웃만)

## 목적
Refresh 토큰 회전·revoke, 로그아웃 (api-contract §1 API-E2-02·03).

## 할 일
- [ ] `POST /api/auth/refresh` — 쿠키 기반, 성공 시 새 Access + 새 Refresh 회전
- [ ] 재사용 감지(이미 revoke된 refresh 재사용) → `AUTH-410 REFRESH_TOKEN_REVOKED` + 전 세션 revoke
- [ ] 응답에 `user` 미포함 (PII 노출 방지, FE는 /me 호출)
- [ ] `POST /api/auth/logout` — 쿠키의 refresh revoke + 쿠키 삭제 Max-Age=0
- [ ] `AUTH-401-001 EXPIRED_TOKEN` 응답 (만료 refresh)

## 산출물
Controller/Service + 테스트 (회전·재사용 감지 시나리오)
