## 할 일
- [ ] `AuthController POST /api/auth/login` (`@Validated` 요청 DTO)
- [ ] `AuthService.login` — email·password 검증, Access/Refresh 발급
- [ ] `refresh_tokens` 테이블·Entity·Repository (해시 저장)
- [ ] Set-Cookie: `refreshToken=<opaque>; HttpOnly; Secure; SameSite=Lax; Path=/api/auth; Max-Age=1209600`
- [ ] 응답 shape: `{accessToken, accessTokenExpiresIn, tokenType, user:{...}}` + `user.requirePasswordChange`·`profileComplete`
- [ ] 에러: `AUTH-401 INVALID_CREDENTIALS` (이메일/비번 구분 안 함)
- [ ] 비번 로그 금지 — `SensitiveDataMasker` 통과
